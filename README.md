This is a web application built using **ASP.NET Core MVC**, following best practices of the MVC architectural pattern. The project aims to demonstrate a modular and maintainable structure suitable for e-commerce or general web applications.

## 🚀 Features

- ASP.NET Core MVC architecture
- Layered structure with Controllers, Models, and Views
- Entity Framework Core support (Code First approach)
- Responsive UI using Bootstrap
- ViewComponents for modular UI parts
- Layout structure for consistent page design

## 🛠 Technologies Used

- .NET 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server (or SQLite)
- Bootstrap 5
- Visual Studio 2022
